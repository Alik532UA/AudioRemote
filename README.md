# AudioRemote

**Комп'ютер грає — телефон керує.**

Дошка звуків для творчої школи: аудіофайли лишаються на комп'ютері біля колонок,
а запускають їх із телефона з іншого кінця зали.

**Адреса:** https://alik532ua.github.io/AudioRemote/

---

## Як цим користуються

**На комп'ютері, який гратиме:**

1. Відкрити застосунок → **Створити дошку**.
2. Дати назву («Зал 2»), отримати ідентифікатор і пароль — на кшталт
   `8S7SC` / `МУШЛЯ-МОЛОКО-ОРБІТА-4723`.
3. Натиснути **«Увімкнути звук на цьому пристрої»** — без цього браузер не
   програє нічого.
4. Обрати папку з музикою. Застосунок вичитає з неї всі аудіофайли; зайві можна
   приховати від пульта.
5. **Лишити вкладку відкритою** — саме вона грає.

У браузері папку доводиться обирати після кожного перезавантаження сторінки, і
це не недоробка інтерфейсу — причина названа в `PROJECT-CONTEXT.md` § 5.0.
Застосунок для комп'ютера (`src-tauri/`) цієї межі не має: там папка —
звичайний шлях, і він пам'ятається.

**З телефона:**

1. Відкрити застосунок → **Підключитися**.
2. Ввести ідентифікатор і пароль, які продиктували.
3. Натискати треки.

Регістр, пробіли замість дефісів і незмінена розкладка на 13 схожих літерах
значення не мають — усе це нормалізується.

## Чого цей застосунок НЕ робить

- **Не завантажує файли нікуди.** Ні в хмару, ні на сервер. Сторінка отримує
  дескриптор теки від людини, і цей дескриптор не покидає комп'ютера.
- **Не працює із закритою вкладкою.** Вебсторінка не може розбудити браузер.
- **Не дає відкликати доступ окремій людині.** Пароль — це адреса дошки; хто
  його знає, той усередині. Щоб закрити доступ, треба створити дошку заново.

## Запуск

Потрібні Node 22.12+ і Java 21 (її вимагає емулятор Firebase).

```bash
npm install
```

Далі **два термінали**. Перший — база:

```bash
npm run emulators
```

Другий — застосунок:

```bash
npm run dev
```

Без емулятора сторінка скаже про це прямо: анонімний вхід нікуди не доїде.

## Перевірки

```bash
npm run check        # типи (обов'язково перед комітом правок .svelte)
npm run lint         # ідіоми
npm test             # юніт-перевірки
npm run check:rules  # правила бази на емуляторі: 12 дозволів і 24 заборони
```

Збірка й гейт над нею:

```bash
MSYS_NO_PATHCONV=1 BASE_PATH=/AudioRemote npm run build && npm run check:build
```

## Застосунок для комп'ютера

`src-tauri/` — тонка оболонка навколо ТІЄЇ САМОЇ сторінки, що лежить за адресою
вище. Вона не вшита в exe, а вантажиться з мережі, тож зміна коду доїжджає
звичайним деплоєм, і перевстановлювати нічого не треба. У exe живе рівно те,
чого браузер не вміє: читання папки з музикою за шляхом, тобто папка за
замовчуванням.

Потрібні Rust (MSVC) і C++ Build Tools:

```bash
winget install Rustlang.Rustup
winget install Microsoft.VisualStudio.2022.BuildTools --override "--quiet --wait --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

```bash
npm run tauri:dev     # вікно з бойовою сторінкою
npm run tauri:build   # інсталятор NSIS у src-tauri/target/release/bundle
```

## Як воно влаштоване

| Шар          | Де                                   | Про що                                                   |
| ------------ | ------------------------------------ | -------------------------------------------------------- |
| Адреса дошки | [`src/lib/board/`](src/lib/board/)   | пароль входить у шлях; уся безпека тут                   |
| Мережа       | [`src/lib/net/`](src/lib/net/)       | RTDB: опис, бібліотека, стан, журнал команд, присутність |
| Звук         | [`src/lib/audio/`](src/lib/audio/)   | дескриптор теки, озброєння, відтворення                  |
| Приймач      | [`src/lib/player/`](src/lib/player/) | виконує команди, оголошує стан                           |
| Пульт        | [`src/lib/remote/`](src/lib/remote/) | надсилає команди, показує стан                           |

Правила доступу — [`database.rules.json`](database.rules.json). Це **єдина межа
безпеки**: публічний конфіг Firebase лежить у бандлі, тож усе, що робить наш
код, може зробити будь-хто з консолі браузера.

Параметри проєкту, свідомі відхилення від канону й **названі межі** —
[`PROJECT-CONTEXT.md`](PROJECT-CONTEXT.md). Прочитати варто до першої правки:
там записано, зокрема, чому приймач працює лише в Chrome/Edge на десктопі й
чому зміна пароля означає нову дошку.
